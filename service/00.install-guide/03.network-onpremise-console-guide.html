Step 1. VPC 생성

경로: VPC > Your VPCs > Create VPC
항목입력값
Name tagbundang-idc-bundang-vpc
IPv4 CIDR192.168.0.0/16
IPv6No

DNS resolution / DNS hostnames 활성화

Step 2. Internet Gateway

경로: VPC > Internet gateways > Create

Name: sillaeng-idc-bundang-igw → VPC에 Attach
