# 02. Network (sillaeng-demo-service-vpc) - AWS 콘솔 배포 가이드

## 개요
Production/Development 통합 VPC를 AWS 콘솔을 통해 수동 배포하는 가이드입니다.

- **리전**: ap-northeast-2 (서울)
- **VPC**: sillaeng-demo-service-vpc (172.25.0.0/22)
- **AWS Profile**: mzc-dsa04

---

## 1. VPC 생성

1. AWS 콘솔 > VPC > Your VPCs > **Create VPC**
2. 설정값:
   - Name tag: `sillaeng-demo-service-vpc`
   - IPv4 CIDR block: `172.25.0.0/22`
   - IPv6 CIDR block: No IPv6 CIDR block
   - Tenancy: Default
3. **Create VPC** 클릭

---

## 2. Internet Gateway 생성 및 연결

1. VPC > Internet Gateways > **Create internet gateway**
2. Name tag: `sillaeng-demo-service-igw`
3. 생성 후 **Actions > Attach to VPC** > `sillaeng-demo-service-vpc` 선택

---

## 4. NAT Gateway 생성 (Regional)

1. VPC > NAT Gateways > **Create NAT gateway**
2. 설정값:
   - Name: `sillaeng-demo-service-nat-regional`
   - Subnet: `service-pub-01a`
   - Connectivity type: Public
   - Availability mode: **Regional** (모든 AZ 커버)
   - Elastic IP allocation: **Allocate Elastic IP** 클릭하여 자동 할당

---

## 5. Route Table 생성 및 설정

### 5.1 Public Route Table

1. VPC > Route Tables > **Create route table**
2. Name: `sillaeng-demo-rt-service-public`
3. VPC: `sillaeng-demo-service-vpc`
4. Routes 추가:
   - Destination: `0.0.0.0/0` → Target: Internet Gateway (`sillaeng-demo-service-igw`)
5. Subnet Associations: `service-pub-01a`, `service-pub-02c`

### 5.2 Private Route Tables (각 티어별)

아래 Route Table을 각각 생성하고, Destination `0.0.0.0/0` → Target: NAT Gateway 설정

| Route Table Name | 연결 서브넷 |
|-----------------|-----------|
| sillaeng-demo-rt-service-private-app | service-pri-app-01a, service-pri-app-02c |
| sillaeng-demo-rt-service-private-gpu-infer | service-pri-gpu-infer-01a, service-pri-gpu-infer-02c |
| sillaeng-demo-rt-service-private-gpu-train | service-pri-gpu-train-01a, service-pri-gpu-train-02c |
| sillaeng-demo-rt-service-private-dev | service-pri-dev-01a, service-pri-dev-02c |

## 7. VPC Endpoint 생성

### 7.1 S3 Gateway Endpoint

1. VPC > Endpoints > **Create endpoint**
2. 설정:
   - Name: `ep-s3-service`
   - Service: `com.amazonaws.ap-northeast-2.s3`
   - Type: Gateway
   - VPC: `sillaeng-demo-service-vpc`
   - Route Tables: service-public, service-private-app, service-private-gpu-infer, service-private-gpu-train, service-private-dev 선택

### 7.2 SSM Interface Endpoints

아래 3개 Interface Endpoint를 동일하게 생성:

| Endpoint Name | Service Name |
|--------------|-------------|
| ep-ssm-service | com.amazonaws.ap-northeast-2.ssm |
| ep-ssmmessages-service | com.amazonaws.ap-northeast-2.ssmmessages |
| ep-ec2messages-service | com.amazonaws.ap-northeast-2.ec2messages |

각 Endpoint 설정:
- Type: Interface
- VPC: `sillaeng-demo-service-vpc`
- Subnets: `service-pri-app-01a`, `service-pri-app-02c`
- Security Group: `service-private-endpoint`
- Enable DNS name: Yes

---

## 8. VPN Gateway (VGW) 생성

1. VPC > Virtual Private Gateways > **Create virtual private gateway**
2. Name: `sillaeng-demo-service-vgw`
3. ASN: Amazon default ASN
4. 생성 후 **Actions > Attach to VPC** > `sillaeng-demo-service-vpc` 선택

---

## 9. Customer Gateway 생성

1. VPC > Customer Gateways > **Create customer gateway**
2. 설정:
   - Name: `sillaeng-demo-sillaeng-cgw-idc`
   - BGP ASN: 65001
   - IP Address: `15.164.136.35` (Openswan EC2 EIP)
   - Routing: Static

---

## 10. VPN Connection 생성

1. VPC > Site-to-Site VPN Connections > **Create VPN connection**
2. 설정:
   - Name: `sillaeng-demo-sillaeng-idc-vpn`
   - Target gateway type: Virtual Private Gateway > `sillaeng-demo-service-vgw`
   - Customer gateway: Existing > `sillaeng-demo-sillaeng-cgw-idc`
   - Routing options: Static
   - Static IP Prefixes: `192.168.0.0/16`

---

## 11. VPN Route Propagation 설정

각 Private Route Table에서:
1. Route Table 선택 > **Route Propagation** 탭
2. **Edit route propagation** > `sillaeng-demo-service-vgw` 체크 > Save

적용 대상 Route Table:
- service-private-app
- service-private-gpu-infer
- service-private-gpu-train
- service-private-dev
- service-private-db
- service-private-devdb
