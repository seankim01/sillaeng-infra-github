# 03. Network On-Premise (bundang-idc-bundang-vpc) - AWS 콘솔 배포 가이드

## 개요
IDC 역할을 하는 On-Premise 시뮬레이션 VPC를 AWS 콘솔을 통해 수동 배포하는 가이드입니다.

- **리전**: ap-northeast-2 (서울)
- **VPC**: bundang-idc-bundang-vpc (192.168.0.0/16)
- **AWS Profile**: mzc-dsa04

---

## 1. VPC 생성

1. AWS 콘솔 > VPC > Your VPCs > **Create VPC**
2. 설정값:
   - Name tag: `bundang-idc-bundang-vpc`
   - IPv4 CIDR block: `192.168.0.0/16`
   - IPv6 CIDR block: No IPv6 CIDR block
   - Tenancy: Default
3. **Create VPC** 클릭

---

## 2. Internet Gateway 생성 및 연결

1. VPC > Internet Gateways > **Create internet gateway**
2. Name tag: `sillaeng-idc-bundang-igw`
3. 생성 후 **Actions > Attach to VPC** > `bundang-idc-bundang-vpc` 선택

---

## 3. Subnet 생성

### 3.1 Public Subnet

| Name | AZ | CIDR | Auto-assign Public IP |
|------|-----|------|----------------------|
| bundang-pub-01a | ap-northeast-2a | 192.168.0.0/25 | Yes |
| bundang-pub-02c | ap-northeast-2c | 192.168.0.128/25 | Yes |

### 3.2 Private Subnet

| Name | AZ | CIDR |
|------|-----|------|
| bundang-pri-01a | ap-northeast-2a | 192.168.1.0/24 |
| bundang-pri-02c | ap-northeast-2c | 192.168.2.0/24 |

---

## 4. NAT Gateway 생성 (Regional)

1. VPC > NAT Gateways > **Create NAT gateway**
2. 설정값:
   - Name: `sillaeng-idc-bundang-nat-regional`
   - Subnet: `bundang-pub-01a`
   - Connectivity type: Public
   - Availability mode: **Regional**
   - Elastic IP allocation: **Allocate Elastic IP** 클릭

---

## 5. Route Table 생성 및 설정

### 5.1 Public Route Table

1. Name: `sillaeng-idc-rt-bundang-public`
2. Routes:
   - `0.0.0.0/0` → Internet Gateway
3. Subnet Associations: `bundang-pub-01a`, `bundang-pub-02c`

### 5.2 Private Route Table

1. Name: `sillaeng-idc-rt-bundang-private`
2. Routes:
   - `0.0.0.0/0` → NAT Gateway
   - `172.25.0.0/22` → Openswan EC2의 ENI (EC2 배포 후 추가)
3. Subnet Associations: `bundang-pri-01a`, `bundang-pri-02c`

---

---

## 7. VPC Flow Logs 설정 (선택사항)

1. VPC 선택 > **Flow Logs** 탭 > **Create flow log**
2. Filter: All
3. Destination: CloudWatch Logs
4. Log group 생성 후 지정
