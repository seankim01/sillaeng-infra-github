# 03. Network On-Premise (IDC VPC) - AWS 콘솔 수동 배포 가이드

## 개요

이 문서는 AWS 콘솔을 통해 IDC 역할의 On-Premise VPC를 수동으로 생성하는 초보자용 가이드입니다.

- **AWS 계정 Profile**: mzc-dsa04
- **리전**: ap-northeast-2 (서울)
- **VPC 이름**: bundang-idc-bundang-vpc
- **CIDR**: 192.168.0.0/16

---

## Step 1. VPC 생성

1. AWS 콘솔 > 검색창에 **VPC** 입력 > VPC 서비스 클릭
2. 왼쪽 메뉴 **Your VPCs** > **Create VPC**
3. 아래와 같이 입력:

| 항목 | 입력값 |
|------|--------|
| Resources to create | VPC only |
| Name tag | bundang-idc-bundang-vpc |
| IPv4 CIDR | 192.168.0.0/16 |
| IPv6 CIDR block | No IPv6 CIDR block |
| Tenancy | Default |

4. **Create VPC** 클릭

---

## Step 2. DNS 설정

1. VPC 선택 > **Actions** > **Edit VPC settings**
2. Enable DNS resolution ✅ / Enable DNS hostnames ✅ 체크
3. **Save**

---

## Step 3. Internet Gateway 생성 및 연결

1. **Internet gateways** > **Create internet gateway**
2. Name: `sillaeng-idc-bundang-igw`
3. 생성 후 **Actions** > **Attach to VPC** > `bundang-idc-bundang-vpc` 선택

---

## Step 4. Subnet 생성

1. **Subnets** > **Create subnet**
2. VPC: `bundang-idc-bundang-vpc`

### Public Subnet

| Name | AZ | CIDR | Auto-assign Public IP |
|------|-----|------|----------------------|
| bundang-pub-01a | ap-northeast-2a | 192.168.0.0/25 | Yes (생성 후 설정) |
| bundang-pub-02c | ap-northeast-2c | 192.168.0.128/25 | Yes (생성 후 설정) |

### Private Subnet

| Name | AZ | CIDR |
|------|-----|------|
| bundang-pri-01a | ap-northeast-2a | 192.168.1.0/24 |
| bundang-pri-02c | ap-northeast-2c | 192.168.2.0/24 |

3. **Create subnet** 클릭

### Public Subnet에 자동 퍼블릭 IP 설정

각 Public Subnet 선택 > **Actions** > **Edit subnet settings** > **Enable auto-assign public IPv4 address** 체크 > **Save**

---

## Step 5. NAT Gateway 생성 (Regional)

1. **NAT gateways** > **Create NAT gateway**
2. 설정:

| 항목 | 입력값 |
|------|--------|
| Name | sillaeng-idc-bundang-nat-regional |
| Subnet | bundang-pub-01a |
| Connectivity type | Public |

3. **Allocate Elastic IP** 클릭 > **Create NAT gateway**

---

## Step 6. Route Table 생성

### 6-1. Public Route Table

1. **Route tables** > **Create route table**
2. Name: `sillaeng-idc-rt-bundang-public` / VPC: `bundang-idc-bundang-vpc`
3. Routes 추가: `0.0.0.0/0` → Internet Gateway
4. Subnet associations: `bundang-pub-01a`, `bundang-pub-02c`

### 6-2. Private Route Table

1. **Create route table**
2. Name: `sillaeng-idc-rt-bundang-private` / VPC: `bundang-idc-bundang-vpc`
3. Routes 추가:
   - `0.0.0.0/0` → NAT Gateway (`sillaeng-idc-bundang-nat-regional`)
   - `172.25.0.0/22` → Network Interface (Openswan EC2의 ENI) — **EC2 배포 후 추가**
4. Subnet associations: `bundang-pri-01a`, `bundang-pri-02c`

---
