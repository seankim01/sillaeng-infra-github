# 05. EC2 On-Premise (IDC Openswan VPN) - AWS 콘솔 배포 가이드

## 개요
bundang-idc-bundang-vpc 내에 Openswan VPN 서버와 Private Bastion을 AWS 콘솔을 통해 수동 배포하는 가이드입니다.

- **리전**: ap-northeast-2 (서울)
- **VPC**: bundang-idc-bundang-vpc (192.168.0.0/16)
- **Key Pair**: mzc-dsa04-shared

---

## 사전 준비

### IAM Role 생성

1. IAM > Roles > **Create role**
2. Trusted entity: AWS service > EC2
3. Permissions: `AmazonEC2RoleforSSM` 정책 연결
4. Role name: `sillaeng-idc-mng-ssm-role`

---

## Openswan 설치 및 VPN 설정

Openswan EC2에 SSH 접속 후 아래 작업을 수행합니다.

### Step 1: Openswan 설치

```bash
sudo yum install -y openswan
```

### Step 2: IP Forwarding 활성화

```bash
sudo vi /etc/sysctl.conf
```

아래 내용 추가:
```
net.ipv4.ip_forward = 1
net.ipv4.conf.default.rp_filter = 0
net.ipv4.conf.default.accept_source_route = 0
net.ipv4.conf.all.rp_filter = 0
net.ipv4.conf.all.send_redirects = 0
net.ipv4.conf.default.send_redirects = 0
net.ipv4.conf.eth0.send_redirects = 0
net.ipv4.conf.default.accept_redirects = 0
net.ipv4.conf.all.accept_redirects = 0
```

적용:
```bash
sudo sysctl -p
```

### Step 3: IPsec 설정

AWS 콘솔에서 VPN Connection 생성 후, **Download Configuration** 버튼으로 설정 파일을 다운로드합니다.
(Vendor: Generic, Platform: Generic, Software: Vendor Agnostic)

다운로드한 설정에서 터널 정보를 확인하여 아래 파일을 작성합니다.

```bash
sudo vi /etc/ipsec.d/aws-vpn.conf
```

```
conn aws-vpn-tunnel1
    type=tunnel
    authby=secret
    left=%defaultroute
    leftid=<Openswan_EIP>
    leftnexthop=%defaultroute
    leftsubnet=192.168.0.0/16
    right=<AWS_Tunnel1_Outside_IP>
    rightsubnet=172.25.0.0/22
    pfs=yes
    auto=start
    ike=aes128-sha1;modp1024
    phase2alg=aes128-sha1;modp1024
    ikelifetime=28800s
    salifetime=3600s
    dpddelay=10
    dpdtimeout=30
    dpdaction=restart_by_peer

conn aws-vpn-tunnel2
    type=tunnel
    authby=secret
    left=%defaultroute
    leftid=<Openswan_EIP>
    leftnexthop=%defaultroute
    leftsubnet=192.168.0.0/16
    right=<AWS_Tunnel2_Outside_IP>
    rightsubnet=172.25.0.0/22
    pfs=yes
    auto=start
    ike=aes128-sha1;modp1024
    phase2alg=aes128-sha1;modp1024
    ikelifetime=28800s
    salifetime=3600s
    dpddelay=10
    dpdtimeout=30
    dpdaction=restart_by_peer
```

### Step 4: Pre-Shared Key 설정

```bash
sudo vi /etc/ipsec.d/aws-vpn.secrets
```

```
<Openswan_EIP> <AWS_Tunnel1_Outside_IP> : PSK "<Tunnel1_PSK>"
<Openswan_EIP> <AWS_Tunnel2_Outside_IP> : PSK "<Tunnel2_PSK>"
```

### Step 5: ipsec.conf 설정

```bash
sudo vi /etc/ipsec.conf
```

```
config setup
    protostack=netkey
    nat_traversal=yes
    virtual_private=%v4:192.168.0.0/16,%v4:172.25.0.0/22
    oe=off

include /etc/ipsec.d/*.conf
```

### Step 6: IPsec 시작

```bash
sudo systemctl enable ipsec
sudo systemctl restart ipsec
```

### Step 7: 상태 확인

```bash
sudo ipsec status
sudo ipsec verify
```

터널 연결 확인:
```bash
sudo ipsec whack --status | grep "established"
```

## Route Table에 VPN 경로 추가

bundang-private Route Table에 sillaeng-demo-service-vpc로 향하는 경로를 추가합니다.

1. VPC > Route Tables > `sillaeng-idc-rt-bundang-private` 선택
2. **Routes** 탭 > **Edit routes**
3. 경로 추가:
   - Destination: `172.25.0.0/22`
   - Target: Network Interface > Openswan EC2의 ENI 선택
4. **Save changes**

---

## VPN 연결 확인

### Openswan 측에서 확인
```bash
# 터널 상태 확인
sudo ipsec status

# Ping 테스트 (Service VPC 내부 IP로)
ping 172.25.0.xxx
```

### AWS 콘솔에서 확인
1. VPC > Site-to-Site VPN Connections
2. 해당 VPN 선택 > **Tunnel details** 탭
3. Status가 **Up**인지 확인
