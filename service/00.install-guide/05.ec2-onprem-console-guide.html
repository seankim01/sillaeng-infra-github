Step 1. EC2 인스턴스 생성

Openswan VPN 서버

경로: EC2 > Instances > Launch instances
항목설정값
Namesillaeng-idc-bundang-ec2-public-bastion
AMIAmazon Linux 2 (2가 아닌 2023은 아님)
Instance typet3.medium
Subnetbundang-pub-01a
Security groupbundang-public-bastion-ec2
Storage20 GiB gp3
필수 설정: Source/Destination Check 비활성화
인스턴스 선택 > Actions > Networking > Change source/destination check > Stop
이 설정이 없으면 VPN 트래픽이 EC2를 통과하지 못합니다!

EIP 할당: Elastic IPs > Allocate > Associate to Openswan 인스턴스

Step 2. Openswan 설치

sudo yum install -y openswan

Step 3. IP Forwarding 활성화

sudo vi /etc/sysctl.conf

# 아래 내용 추가
net.ipv4.ip_forward = 1
net.ipv4.conf.default.rp_filter = 0
net.ipv4.conf.all.rp_filter = 0
net.ipv4.conf.all.send_redirects = 0
net.ipv4.conf.default.send_redirects = 0
net.ipv4.conf.eth0.send_redirects = 0
net.ipv4.conf.default.accept_redirects = 0
net.ipv4.conf.all.accept_redirects = 0

# 적용
sudo sysctl -p

4-1. /etc/ipsec.conf

config setup
    protostack=netkey
    nat_traversal=yes
    virtual_private=%v4:10.0.0.0/8,%v4:192.168.0.0/16,%v4:172.16.0.0/12
    oe=off

include /etc/ipsec.d/*.conf

4-2. /etc/ipsec.d/aws-vpn.conf

conn aws-vpn-tunnel1
    type=tunnel
    authby=secret
    left=<Openswan_Private_IP>      # hostname -I 로 확인
    leftid=<Openswan_EIP>            # 3.34.225.161
    leftnexthop=%defaultroute
    leftsubnet=192.168.0.0/16
    right=<AWS_Tunnel1_Outside_IP>   # VPN 콘솔에서 확인
    rightsubnet=172.25.0.0/22
    pfs=yes
    auto=start
    ike=aes128-sha1;modp1024
    phase2alg=aes128-sha1;modp1024
    ikelifetime=28800s
    salifetime=3600s
    dpddelay=10
    dpdtimeout=30
    dpdaction=restart_by_peer
    overlapip=yes

conn aws-vpn-tunnel2
    type=tunnel
    authby=secret
    left=<Openswan_Private_IP>
    leftid=<Openswan_EIP>
    leftnexthop=%defaultroute
    leftsubnet=192.168.0.0/16
    right=<AWS_Tunnel2_Outside_IP>
    rightsubnet=172.25.0.0/22
    pfs=yes
    auto=start
    ike=aes128-sha1;modp1024
    phase2alg=aes128-sha1;modp1024
    ikelifetime=28800s
    salifetime=3600s
    dpddelay=10
    dpdtimeout=30
    dpdaction=restart_by_peer
    overlapip=yes

4-3. /etc/ipsec.d/aws-vpn.secrets

<EIP> <Tunnel1_IP> : PSK "<Tunnel1_PSK>"
<EIP> <Tunnel2_IP> : PSK "<Tunnel2_PSK>"

Step 5. iptables FORWARD 허용

sudo iptables -I FORWARD 1 -s 192.168.0.0/16 -d 172.25.0.0/22 -j ACCEPT
sudo iptables -I FORWARD 2 -s 172.25.0.0/22 -d 192.168.0.0/16 -j ACCEPT
sudo service iptables save
중요: 이 규칙이 없으면 VPN 터널은 UP이지만 실제 트래픽이 포워딩되지 않습니다!

Step 6. IPsec 시작 및 확인

sudo systemctl enable ipsec
sudo systemctl restart ipsec

# 상태 확인
sudo ipsec status
sudo ipsec whack --status | grep "established"
성공 확인: AWS 콘솔 > VPC > VPN connections > Tunnel details에서 Status: UP 확인
