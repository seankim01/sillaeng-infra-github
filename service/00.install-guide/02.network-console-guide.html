Step 1. VPC 생성

경로: AWS 콘솔 > VPC > Your VPCs > Create VPC
항목입력값
Resources to createVPC only
Name tagsillaeng-demo-service-vpc
IPv4 CIDR172.25.0.0/22
IPv6 CIDR blockNo IPv6 CIDR block
TenancyDefault

생성 후 VPC 선택 > Actions > Edit VPC settings에서:

  • Enable DNS resolution ✅
  • Enable DNS hostnames ✅

Step 2. Internet Gateway 생성

경로: VPC > Internet gateways > Create internet gateway
  1. Name tag: sillaeng-demo-service-igw
  2. 생성 후 Actions > Attach to VPC > sillaeng-demo-service-vpc 선택

생성 순서

  1. VGW 생성: Name: sillaeng-demo-service-vgw → VPC에 Attach
  2. CGW 생성: BGP ASN: 65001, IP: 3.34.225.161
  3. VPN Connection 생성: Static Routing, Static Route: 192.168.0.0/16
  4. Route Propagation: 모든 Private RT에서 VGW propagation 활성화
주의: VPN Connection 생성 후, Openswan EC2에서 IPsec 설정을 완료해야 터널이 UP됩니다. (05번 가이드 참조)
