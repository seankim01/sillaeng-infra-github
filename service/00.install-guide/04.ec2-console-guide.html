사전 준비: IAM Role 생성

경로: IAM > Roles > Create role
  1. Trusted entity: AWS service > EC2
  2. Permissions: AmazonEC2RoleforSSM 검색 후 체크
  3. Role name: sillaeng-demo-service-ssm-role

User Data (웹서버 자동 설치)

#!/bin/bash
apt update -y
apt install -y apache2
systemctl enable apache2
systemctl start apache2
HOSTNAME=$(hostname)
LOCAL_IP=$(hostname -I | awk '{print $1}')
cat > /var/www/html/index.html <<HTML
<!DOCTYPE html>
<html><body>
<h2>Server Information</h2>
<p>Hostname: ${HOSTNAME}</p>
<p>IP: ${LOCAL_IP}</p>
</body></html>
HTML

SSH 접속 흐름

sequenceDiagram
    participant User as 로컬 PC
    participant Bastion as Bastion (Public)
    participant GPU as GPU 서버 (Private)
    participant Dev as 개발 서버 (Private)

    User->>Bastion: SSH (EIP:22)
    Bastion->>GPU: SSH ProxyJump (172.25.1.x:22)
    Bastion->>Dev: SSH ProxyJump (172.25.2.x:22)

SSH Config 예시 (~/.ssh/config)

Host sillaeng-aws-bastion
    HostName <Bastion_EIP>
    User ec2-user
    IdentityFile ~/.ssh/mzc-dsa04-shared.pem

Host sillaeng-aws-gpu
    HostName <GPU_Private_IP>
    User ubuntu
    IdentityFile ~/.ssh/mzc-dsa04-shared.pem
    ProxyJump sillaeng-aws-bastion

Host sillaeng-aws-dev
    HostName <Dev_Private_IP>
    User ubuntu
    IdentityFile ~/.ssh/mzc-dsa04-shared.pem
    ProxyJump sillaeng-aws-bastion
