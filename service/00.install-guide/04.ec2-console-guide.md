# 04. EC2 (Service VPC 인스턴스) - AWS 콘솔 배포 가이드

## 개요
sillaeng-demo-service-vpc 내에 EC2 인스턴스를 AWS 콘솔을 통해 수동 배포하는 가이드입니다.

- **리전**: ap-northeast-2 (서울)
- **VPC**: sillaeng-demo-service-vpc (172.25.0.0/22)
- **Key Pair**: mzc-dsa04-shared

---

## 사전 준비

### IAM Role 생성 (EC2용 SSM Role)

1. IAM > Roles > **Create role**
2. Trusted entity: AWS service > EC2
3. Permissions: `AmazonEC2RoleforSSM` 정책 연결
4. Role name: `sillaeng-demo-service-ssm-role`
5. Instance Profile이 자동 생성됨

### Key Pair 확인

1. EC2 > Key Pairs에서 `mzc-dsa04-shared` 키가 존재하는지 확인
2. 없으면 **Create key pair**로 생성

---

## EC2 인스턴스 생성

EC2 > Instances > **Launch instances**

### 1. Bastion Host

| 항목 | 설정값 |
|------|--------|
| Name | sillaeng-demo-service-ec2-bastion |
| AMI | Amazon Linux 2023 (최신) |
| Instance type | t3.micro |
| Key pair | mzc-dsa04-shared |
| Network | sillaeng-demo-service-vpc |
| Subnet | service-pub-01a |
| Auto-assign Public IP | Enable |
| Security Group | service-pub-bastion-ec2 |
| Storage | 30 GB gp3 |
| IAM Instance Profile | sillaeng-demo-service-ssm-role |

배포 후 **Elastic IP 할당**:
1. EC2 > Elastic IPs > **Allocate Elastic IP address**
2. 할당된 EIP를 Bastion 인스턴스에 Associate
