# 04. EC2 (Service VPC 인스턴스) - AWS 콘솔 수동 배포 가이드

## 개요

이 문서는 AWS 콘솔을 통해 sillaeng-demo-service-vpc 내에 EC2 인스턴스를 수동으로 생성하는 초보자용 가이드입니다.

- **AWS 계정 Profile**: mzc-dsa04
- **리전**: ap-northeast-2 (서울)
- **VPC**: sillaeng-demo-service-vpc (172.25.0.0/22)
- **Key Pair**: mzc-dsa04-shared

---

## 사전 준비

### A. IAM Role 생성 (EC2용 SSM)

EC2에서 AWS Systems Manager(SSM)를 사용하려면 IAM Role이 필요합니다.

1. AWS 콘솔 > 검색창에 **IAM** 입력 > IAM 서비스 클릭
2. 왼쪽 메뉴 **Roles** > **Create role**
3. 설정:
   - Trusted entity type: **AWS service**
   - Use case: **EC2** 선택 > **Next**
4. Permissions:
   - 검색창에 `AmazonEC2RoleforSSM` 입력 > 체크 > **Next**
5. Role name: `sillaeng-demo-service-ssm-role`
6. **Create role**

### B. Key Pair 확인

1. EC2 > 왼쪽 메뉴 **Key Pairs**
2. `mzc-dsa04-shared`가 있는지 확인
3. 없으면 **Create key pair** > Name: `mzc-dsa04-shared` > Type: RSA > Format: .pem > **Create**
4. 다운로드된 .pem 파일을 `~/.ssh/` 에 저장하고 권한 설정:
   ```bash
   chmod 600 ~/.ssh/mzc-dsa04-shared.pem
   ```

## EC2 인스턴스 생성

EC2 > **Instances** > **Launch instances**

---

### 인스턴스 1: Bastion Host

Bastion은 외부에서 Private 인스턴스에 접근하기 위한 중간 서버입니다.

| 항목 | 설정값 |
|------|--------|
| Name | sillaeng-demo-service-ec2-bastion |
| AMI | Amazon Linux 2023 (검색창에 "Amazon Linux 2023" 입력) |
| Instance type | t3.small |
| Key pair | mzc-dsa04-shared |
| Network settings > VPC | sillaeng-demo-service-vpc |
| Subnet | service-pub-01a |
| Auto-assign public IP | Enable |
| Security group | Select existing > `service-pub-bastion-ec2` |
| Storage | 30 GiB, gp3 |
| Advanced > IAM instance profile | sillaeng-demo-service-ssm-role |

**생성 후 Elastic IP 할당:**
1. EC2 > 왼쪽 메뉴 **Elastic IPs** > **Allocate Elastic IP address** > **Allocate**
2. 할당된 EIP 선택 > **Actions** > **Associate Elastic IP address**
3. Instance: Bastion 인스턴스 선택 > **Associate**

| Network settings > VPC | sillaeng-demo-service-vpc |
| Subnet | service-pri-dev-01a |
| Auto-assign public IP | Disable |
| Security group | Select existing > `service-private-dev-ec2` |
| Storage | 100 GiB, gp3 |
| Advanced > IAM instance profile | sillaeng-demo-service-ssm-role |
| Advanced > User data | 아래 스크립트 입력 |

**User data (웹서버 자동 설치):**
```bash
#!/bin/bash
apt update -y
apt install -y apache2
systemctl enable apache2
systemctl start apache2
HOSTNAME=$(hostname)
LOCAL_IP=$(hostname -I | awk '{print $1}')
cat > /var/www/html/index.html <<HTML
<!DOCTYPE html>
<html>
<body>
<h2>Server Information</h2>
<p>Hostname: ${HOSTNAME}</p>
<p>IP: ${LOCAL_IP}</p>
</body>
</html>
HTML
```

## SSH 접속 방법

```bash
# Bastion 직접 접속
ssh -i ~/.ssh/mzc-dsa04-shared.pem ec2-user@<Bastion_EIP>

# Private 인스턴스 접속 (Bastion 경유)
ssh -i ~/.ssh/mzc-dsa04-shared.pem -o ProxyCommand="ssh -i ~/.ssh/mzc-dsa04-shared.pem -W %h:%p ec2-user@<Bastion_EIP>" ubuntu@<Private_IP>
```

SSH config 설정 (`~/.ssh/config`):
```
Host sillaeng-aws-bastion
    HostName <Bastion_EIP>
    User ec2-user
    IdentityFile ~/.ssh/mzc-dsa04-shared.pem

Host sillaeng-aws-gpu
    HostName <GPU_Private_IP>
    User ubuntu
    IdentityFile ~/.ssh/mzc-dsa04-shared.pem
    ProxyJump sillaeng-aws-bastion

Host sillaeng-aws-dev
    HostName <Dev_Private_IP>
    User ubuntu
    IdentityFile ~/.ssh/mzc-dsa04-shared.pem
    ProxyJump sillaeng-aws-bastion
```
